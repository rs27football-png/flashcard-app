# 単語帳アプリ

応用情報技術者試験および大学講義の試験対策に用いる, 個人用の単語帳アプリ (PWA).

公開先: https://rs27football-png.github.io/flashcard-app/

## 状態

`specs.md` §8 の段階0〜7をすべて実装済み. 残作業は §6.2 の P1〜P4 (データ消失を防ぐための案内) のみ.

## 機能

- 学習セットのフォルダ管理 (階層は任意, ドラッグで移動)
- カード作成 (手動入力 / テキストインポート)
- 暗記モード (左右への振り分け, 進捗の永続保存, 1つ戻る, 中断と再開)
- 4択モード (選択肢の自動生成, 結果画面, 誤答のみ再挑戦)
- ★マーキング, セットのコピー・統合・分割
- 全セット横断検索 (ひらがな / カタカナ / 全角半角を同一視)
- 画像の添付と数式 (LaTeX) の描画. 学習セットごとに有効化
- オフライン動作 (PWA), ZIP / JSON によるバックアップ

## 使い方

### 端末に入れる

iPhone は Safari で上記の URL を開き, 共有 → 「ホーム画面に追加」. PC は Chrome / Edge のアドレスバー右のインストールボタンから入れられる. 一度開けば, 以降は通信がなくても学習できる.

### データの保存場所

学習データはすべて**その端末のブラウザの中** (IndexedDB) に保存される. サーバには何も送られないため, 端末をまたいで自動で同期されることはない.

### 端末間で揃える

設定 (ホームの歯車) → バックアップ から書き出し, もう一方の端末で取り込む.

| 方式 | 結果 | 用途 |
|---|---|---|
| 置き換え | 取り込む側の既存データをすべて消してから復元する. 進捗まで一致する | 端末間で状態を揃える |
| マージ | 既存を残して足す. 同じセットを2回取り込むと2つになる | 他の端末から特定のセットを持ち込む |

**編集する端末は1つに決めること.** 両方で編集してから互いに取り込むと, 一方の編集が失われるか重複する. 詳細は `specs.md` §4.11 を参照.

## 開発

```bash
npm install   # 依存をインストールする (初回のみ)
npm run dev   # 開発サーバを起動する
npm run build # 本番ビルドを dist/ に出力する
npm run lint  # 静的検査を走らせる
```

`main` への push で GitHub Actions が GitHub Pages へ自動公開する. 段階1以降は直接 push せず, ブランチを切って PR 経由でマージする (`CLAUDE.md` 参照).

## 構成

```
src/
  core/        # UI に依存しないロジック層. React を import しない
    db/        # Dexie (IndexedDB) のスキーマとデータアクセス
    study/     # キュー構築, 4択の選択肢生成
    import/    # テキストインポートの解析
    search/    # 検索用の正規化と照合
    media/     # 画像の圧縮
    math/      # 数式の切り出し
    backup/    # ZIP / JSON の書き出しと読み込み
    types.ts   # データモデルの型定義
  ui/
    screens/   # 画面単位のコンポーネント (specs.md の S1〜S10 に対応)
    components/
    hooks/
```

技術構成: TypeScript + React + Vite / Dexie.js (IndexedDB) / KaTeX / fflate / vite-plugin-pwa / GitHub Pages
